Archivos importados

Sube Excel (.xlsx) o CSV (.csv) para agregar filas a un área. Se conservan las fuentes existentes; el sistema valida encabezados y vuelve a importar los datos.

Máximo 20 MB. Se aceptan nombres equivalentes de columnas y se conservan las columnas adicionales. Los campos opcionales pueden omitirse; las filas con campos obligatorios vacíos o valores no válidos se rechazan.
